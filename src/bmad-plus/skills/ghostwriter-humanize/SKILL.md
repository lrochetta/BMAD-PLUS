# Revise for natural expression

Open the Ghostwriter pack beside the installed skills. Read its [editorial contract](../pack-ghostwriter/shared/editorial-contract.md). The [humanize workflow](../pack-ghostwriter/workflows/humanize.md) describes the full task. In a source checkout these resources live in `../../packs/pack-ghostwriter/` under the same relative names. If a required resource is missing, identify its path before proceeding.

1. Read the whole message and its conversational context. Identify the actual question, reader and voice. In a mixed document, identify the permitted prose fields and keep the technical regions intact. If you can see only an excerpt, state the extent of the review.
2. Locate a few exact passages where wording slows the reader. For AI slop, ask what information the reader would lose if the sentence disappeared. Cut filler, empty praise and unsupported superlatives. For writing patterns, compare nearby paragraphs or chat turns for repeated openings, forced contrasts, artificial groups of three and endings that echo the question. A single word, triad, dash or recurring technical term can be appropriate. Judge its function in this passage.
3. Make a targeted edit. Put the useful information where the reader needs it. Keep a genuine qualification, meaningful repetition, customary typographic spacing and the author's rhythm. If the author has asked to keep a particular phrase, preserve it through subsequent passes on this draft. Apply that preference elsewhere only if the author gave it wider scope. Never add a fabricated personal experience, intentional error or filler to simulate a voice.
4. Read the revision aloud or sound it out in the context of the next turn. Compare the original and final text for actor, quantities, quotes, links, uncertainty, conditions and actions. Restore any altered commitment.
5. If the copy answers the reader, deliver it alone, unchanged when it already works. Flag a missing essential fact in a separate note to the author. In “text only” mode, ask one factual question before drafting only if the gap prevents a usable reply. Otherwise return just the requested text. For an audit, cite the passage and explain its effect on this reader. A stylistic edit establishes neither human authorship nor removal of a statistical watermark.

A French support chat opens with “C’est une excellente question. Il convient de noter que le lien expirera vendredi à midi.” If the reader asked when to use the link, “Le lien expirera vendredi à midi.” answers the turn. Retain the hour and day. A later promise of renewal would require evidence.
