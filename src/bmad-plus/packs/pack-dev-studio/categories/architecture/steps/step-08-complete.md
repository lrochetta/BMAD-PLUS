# Architecture compatibility guide — hand off the design

This retained path corresponds to procedure step 8 of
[create-architecture](../create-architecture.md). Follow the common
[execution guide](../../../shared/execution.md).

Review the report for consistency between requirements, decisions, interfaces and
delivery order. Keep actual validation results separate from proposed checks.
Identify which decisions are accepted, provisional or superseded.

State the first useful implementation slice, its acceptance path and any unresolved
prerequisite. The report may be delivered as a draft when a consequential decision
lacks evidence. Do not turn document completion into a claim of verified software.

Preserve human additions and provide the changed artifact locations. Continuation
starts by comparing current inputs with this handoff, then resumes the earliest
affected work. This path does not commit, publish or start another workflow.
