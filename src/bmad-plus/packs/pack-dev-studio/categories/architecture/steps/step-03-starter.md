# Architecture compatibility guide — choose a foundation

This retained path corresponds to procedure step 3 of
[create-architecture](../create-architecture.md). Follow the common
[execution guide](../../../shared/execution.md).

Inspect the existing manifests, infrastructure and extension points first. A
starter selection is relevant only when the project actually needs a new
foundation. Preserve established tools unless a requirement justifies changing
them.

For a new system, compare credible foundations against deployment, maintenance,
team constraints and the behavior to deliver. Verify mutable technical claims
against current authoritative documentation when source access is available.
Record unsupported claims as unverified.

Write the rationale, constraints and compatibility consequences in the report.
Selection does not install packages or scaffold the project. On resume, recheck
the assumptions affected by changed requirements or environment and continue the
main procedure without creating a separate mandatory setup phase.
