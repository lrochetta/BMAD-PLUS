# Agent output review

Read the [editorial contract](../shared/editorial-contract.md). Use `ghostwriter-verify` on the assembled deliverable. In an orchestrated run, leave acceptance to the controller.

## Inputs

Obtain the actual draft, brief, sources, profile version, policy, selected paths or fields, and attempt identity. Reuse an existing report only when it covers this exact version, policy and scope. For a manual review, describe the evidence that can be inspected in the current session.

## Procedure

1. Check that the selected deliverable exists and the proposed edits fall within the allowed prose. Record every selected unit, including joins in a multi-author document. Keep the source version available through failure and retry.
2. Bind the inputs and output to the identities observed by the controller when available. For each unit, record its disposition, including reviewed and unchanged text. Mark missing units and unreadable or unsupported content.
3. Compare source and candidate. Check literal protections and scope mechanically where the format supports it. Examine negation, actors, numeric bounds, exceptions, obligations, source attribution, meaningful omissions and added claims in context. Anchor a finding in both passages.
4. Record preparation, fidelity, factual support and editorial quality separately. State the sources actually used for factual checking. If a separate reviewer is required, obtain a distinct observed execution for the comparison. A worker name in the draft is insufficient evidence of separation.
5. If a correction is allowed and the attempt budget permits it, send the blocking observations to the editor. Collect the corrected artifact as a new attempt and review the new version, including affected transitions. Reconcile interrupted work before retry. Keep partial coverage, stale inputs or missing evidence visible as incomplete.
6. Hand the exact candidate and anchored report to the controller. A blocking change in meaning remains a finding even when all mechanical checks pass. Any change to a bound artifact or reference after review requires fresh evidence for the changed version.

## Delivery

Give the report, coverage and outstanding findings separately from the proposed prose. Indicate whether the controller accepted the exact output only when its decision has been observed. A prepared plan or an editor's self-assessment does not establish acceptance.
